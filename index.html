Vérifier une facture

Entrez le code de vérification imprimé au bas d’une facture ou d’un avoir émis avec Ilmtechlwo_pro.

Cette page ne montre jamais le nom du client ni les montants. Seuls le type, le numéro, la date d’émission, le statut, le nom de l’émetteur et une empreinte sont affichés. Comparez l’empreinte avec celle imprimée sur le document : si elle est différente, le document a été modifié. Ilmtechlwo_pro n’est pas un système de facturation certifié par l’administration fiscale.
